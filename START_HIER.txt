FRAMECUT 3.6 — START

1. Das ZIP vollständig in einen NEUEN Ordner entpacken.
2. Den Ordner mit dieser Datei und start.sh öffnen.
3. Für einen Menüeintrag einmal `bash install.sh` ausführen; alternativ direkt starten.
4. Rechtsklick auf freie Fläche → Im Terminal öffnen.
5. Eingeben: bash start.sh
